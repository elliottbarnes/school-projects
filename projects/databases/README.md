# Database Exercises

Database coursework by Elliott Barnes covering normalization and SQL queries.

- `normalization-notes.md` discusses functional dependencies and a third-normal-form decomposition.
- `queries.sql` contains SQLite-oriented queries written against the Chinook sample schema.

The assignment prompts and database file are excluded. To try the queries, obtain a licensed copy of the Chinook sample database and run the statements selectively; they were not executed during this curation pass.
