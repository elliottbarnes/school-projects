# Image Processing Algorithms

Selected Java algorithm code from group coursework by Elliott Barnes and Zachary Smith.

## Included

- `DerivativeofGaussian.java`: derivative-kernel and image-derivative calculations.
- `CornerResponse.java`: structure-tensor response calculations used for corner detection.

The original UI framework, assignment reports, submission archives, compiled classes, and course-provided images are excluded. These classes are source excerpts rather than a standalone application. Compilation could not be rerun because a Java runtime was unavailable in the verification environment.
