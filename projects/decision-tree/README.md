# Decision Tree

Group-authored Python coursework by Elliott Barnes and Jesse Hanlon for growing, evaluating, pruning, and displaying a decision tree.

## Files

- `growTree.py`: information-gain calculations and recursive tree construction.
- `pruneTree.py`: prediction, accuracy calculation, and pruning routines.
- `disp.py`: text rendering for a saved tree.
- `evaluate.py`: an incomplete evaluation entry point retained for historical accuracy.

## Requirements and limitations

The scripts require Python and NumPy. The original training/test data and submission material are excluded, so the programs are not runnable as-is. Relative data paths reflect the historical project layout.
